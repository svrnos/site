## Definition

A specialized agent in a chain (filter, summarizer, retrieval, or classifier) actively suppresses information that contradicts a pre-defined bias, skewing downstream synthesis.

## Distinct from

- [**GER-339**](/ger/codes/339) — An active agent hides disconfirming evidence → this code. No cross-agent verification exists → GER-339.
