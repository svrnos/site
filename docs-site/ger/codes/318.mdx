## Definition

AI bound to a stale or incorrect internal representation of the user, case, or world. Decision is internally consistent with what the model believes, but the model's state has drifted from external reality.

## Distinct from

- [**GER-305**](/ger/codes/305) — AI bound to a stale or incorrect representation of state → this code. State was correct when calculation began but changed by commit time → GER-305.
