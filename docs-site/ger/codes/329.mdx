## Definition

AI training or processing pipeline ingests, retains, or continues processing personal data, copyrighted works, biometric records, or non-consented creative content without an upstream consent, license, withdrawal, or retention gate.

## Distinct from

- [**GER-324**](/ger/codes/324) — General training-data consent failure → this code. Biometric-specific input consent failure → GER-324.
- [**GER-346**](/ger/codes/346) — Individual or organizational consent failure → this code. Collective sovereignty failure over community knowledge → GER-346.
