*Operator / Platform Errors*

## Definition

A governance rule communicated through informal channels (verbal, chat, email, meeting decisions, hallway conversations) never makes the transition to platform-recognized policy or production enforcement. The rule is recoverable from communication records but does not appear in any authoritative ruleset. Three structural properties: (1) the rule was stated through an informal channel, (2) the rule is recoverable from phone logs, email archives, chat history, or meeting minutes, (3) the rule never reached the authoritative ruleset (no ticket, no policy doc update, no code change, no formal compliance entry).

## Distinct from

- [**GER-404**](/ger/codes/404) — Rule recoverable from communication records but not in active ruleset → this code. No rule exists anywhere in the system → GER-404.
- [**GER-420**](/ger/codes/420) — Rule never reached the platform's formal policy layer at all → this code. Rule exists in formal platform policy (prompt, written policy doc, configuration) but not wired into production → GER-420.
- [**GER-400**](/ger/codes/400) — Rule well-formed when communicated, just never codified → this code. Rule ambiguous or self-contradicting → GER-400.
