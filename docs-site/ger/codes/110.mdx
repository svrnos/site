## Definition

The system enters a degraded mode (e.g., CPU fallback) without signaling it, so downstream consumers act on degraded output as if normal.

## Distinct from

- [**GER-101**](/ger/codes/101) — Missing degraded-mode signal is the initiating failure → this code. The substrate event itself is the initiating failure → GER-101.
