## Definition

Same user identity persists across surfaces (web, mobile, API) but the governance state — policies applied, attestations made, refusals recorded — fails to synchronize between surfaces. Cross-surface continuity is preserved while coherence breaks.

## Distinct from

- [**GER-313**](/ger/codes/313) — Cross-surface state fails to synchronize → this code. Drift in what is shown to user on a single surface → GER-313.
