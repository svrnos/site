*Operator / Platform Errors*

## Definition

Platform knows a user or use case is prohibited, but enforcement is not wired into the product. The prohibition exists in policy; it does not exist in production.

## Distinct from

- [**GER-306**](/ger/codes/306) — Stated prohibition never wired from the start → this code. Publicly committed constraint actively retired → GER-306.
- [**GER-404**](/ger/codes/404) — Rule exists in policy, enforcement never wired in production → this code. No rule exists in the active ruleset → GER-404.
