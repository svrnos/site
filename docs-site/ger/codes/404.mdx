*Operator / Platform Errors*

## Definition

No matching rule found in active ruleset for this harm category. The lookup returned empty.

## Distinct from

- [**GER-307**](/ger/codes/307) — No rule in the active ruleset for this harm → this code. Rule exists but is never invoked at decision time → GER-307.
- [**GER-400**](/ger/codes/400) — Lookup returned empty → this code. Rule found but malformed → GER-400.
