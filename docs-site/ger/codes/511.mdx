*Infrastructure Failures*

## Definition

A required verification or credential gate was never enforced at the access point before the high-risk session began.

## Distinct from

- [**GER-401**](/ger/codes/401) — Precondition gate never installed at session start → this code. Identity verification missing during live session → GER-401.
