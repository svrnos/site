*Operator / Platform Errors*

## Definition

The same AI vendor's models generate content and evaluate it, producing systematic bias toward their own output with no governance layer to detect or correct the conflict.

## Distinct from

- [**GER-318**](/ger/codes/318) — Operator mental model diverges from system actual state → this code. System internal model diverges from external truth → GER-318.
