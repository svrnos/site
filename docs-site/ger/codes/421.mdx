*Operator / Platform Errors*

## Definition

A governed AI system processed a request outside its intended deployment domain. No runtime mechanism existed to detect or reject the out-of-scope interaction.

## Distinct from

- [**GER-420**](/ger/codes/420) — Adversary defeated active enforcement → this code. Enforcement was never installed in production → GER-420.
- [**GER-425**](/ger/codes/425) — General adversarial defeat of enforcement → this code. Identity verification specifically defeated by synthesis → GER-425.
