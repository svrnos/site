*Operator / Platform Errors*

## Definition

High-risk AI surface available without verifying identity, age, role, or authority of the user before access is granted.

## Distinct from

- [**GER-420**](/ger/codes/420) — Identity gate never installed at session start → this code. Stated prohibition not wired at runtime → GER-420.
- [**GER-511**](/ger/codes/511) — Identity verification missing at runtime → this code. Verification gate never installed at access point → GER-511.
