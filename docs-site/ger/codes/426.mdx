*Operator / Platform Errors*

## Definition

Autonomous agent given credentials whose blast radius exceeds its judgment envelope; agent executes actions with permanent or expensive consequences that exceed any individual sub-task's apparent scope.

## Distinct from

- [**GER-316**](/ger/codes/316) — Authority over-granted from the start → this code. Authority lapsed during operation → GER-316.
- [**GER-420**](/ger/codes/420) — Agent blast radius exceeded its judgment envelope → this code. Stated rule against action existed but enforcement absent → GER-420.
