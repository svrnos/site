*Infrastructure Failures*

## Definition

Platform attempts escalation to an external system or authority. The handoff response is received but invalid, incomplete, or unusable.

## Distinct from

- [**GER-500**](/ger/codes/500) — External system returned invalid response → this code. Platform own internal code crashed → GER-500.
- [**GER-504**](/ger/codes/504) — Response received but unusable → this code. No response received at all → GER-504.
