## Definition

Hardware, thermal, or power throttling reduces numerical precision or pushes latency past the operational envelope, degrading model behavior.

## Distinct from

- [**GER-110**](/ger/codes/110) — The substrate event is the initiating failure → this code. The absence of a degraded-mode signal is the initiating failure → GER-110.
