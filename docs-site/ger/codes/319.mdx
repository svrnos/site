## Definition

Same structural failure recurs across documented events without the vendor's recognition apparatus updating. Each event is treated as isolated; no incorporation into safety design.

## Distinct from

- [**GER-309**](/ger/codes/309) — Same pattern recurs without recognition apparatus updating → this code. Vendor measured the harm once and shipped anyway → GER-309.
