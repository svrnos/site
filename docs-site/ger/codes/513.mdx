*Infrastructure Failures*

## Definition

A system used to enhance, reconstruct, or unmask degraded or occluded source media originates fabricated forensic detail that the user treats as recovered or authoritative truth.

## Distinct from

- [**GER-512**](/ger/codes/512) — Fabrication framed as recovered/enhanced from a source → this code. Fabrication invented from scratch, not framed as recovery → GER-512.
- [**GER-327**](/ger/codes/327) — Enhance-to-fabricate of degraded source → this code. Deepfake synthesized from scratch → GER-327.
