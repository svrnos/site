*Structural Moves*

## Definition

Drift in the enforceable boundaries a system holds: execution rights, gate thresholds, and access levels shift over time in ways that change what the system will actually do, while the user-facing policy text remains stable. The system authorizes actions the published policy doesn't cover. Architecture governs action.

## Distinct from

- [**GER-313**](/ger/codes/313) — Drift in execution boundaries while user-facing policy stays stable → this code. Drift in defaults and surfaced options without rule change → GER-313.
- [**GER-420**](/ger/codes/420) — Boundary silently expanded over time → this code. Stated prohibition never wired from the start → GER-420.
