## Definition

Biometric data (face, voice, gait, fingerprint, micro-expression) collected, stored, or sold without informed consent in jurisdictions where legally required.

## Distinct from

- [**GER-322**](/ger/codes/322) — Biometric data collected without consent at input → this code. Output authenticity missing at runtime → GER-322.
