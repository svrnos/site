## Definition

Alignment or safety tuning is calibrated for a default sociocultural or historical norm but produces skewed, inaccurate, or erased outcomes when applied to a specific cultural, historical, or domain context.

## Distinct from

- [**GER-342**](/ger/codes/342) — Calibration to a default sociocultural/historical norm → this code. Alignment-induced asymmetric bias more broadly → GER-342.
- [**GER-318**](/ger/codes/318) — Calibration-to-norm failure → this code. Bound to a stale internal world-representation → GER-318.
