*Infrastructure Failures*

## Definition

Detection fired correctly. Internal enforcement executed. No escalation path to human oversight or law enforcement was ever built.

## Distinct from

- [**GER-500**](/ger/codes/500) — Handler was never implemented → this code. Platform own code crashed during operation → GER-500.
- [**GER-504**](/ger/codes/504) — Escalation path never built → this code. Escalation path exists but external handler timed out → GER-504.
