*Infrastructure Failures*

## Definition

Platform sends a case to an external reviewer, vendor, agency, or authority. No timely acknowledgment or action is received before the risk window closes.

## Distinct from

- [**GER-408**](/ger/codes/408) — External handoff timed out → this code. Internal SLA breached → GER-408.
- [**GER-501**](/ger/codes/501) — Handoff exists but external party did not respond → this code. No escalation handler ever built → GER-501.
