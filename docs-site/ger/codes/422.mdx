*Operator / Platform Errors*

## Definition

Vendor materially overstates model capability (accuracy, "AI-powered", compliance coverage, certified-result claims) leading operator over-reliance to produce harm.

## Distinct from

- [**GER-309**](/ger/codes/309) — Vendor overstated capability without necessarily knowing real accuracy → this code. Vendor measured the specific harm and shipped anyway → GER-309.
