*Operator / Platform Errors*

## Definition

Governance is anchored to a control point that is not the actual point of irreversibility. The true point of no return was not identified during design, so the enforcement gate sits before or beside the consequential commit and never governs it. The control appears present and may pass, but it is bound to the wrong moment in the action path.

## Distinct from

- [**GER-305**](/ger/codes/305) — The commit point itself is misidentified → this code. State changed between check and commit at a correctly-located point → GER-305.
- [**GER-314**](/ger/codes/314) — The boundary was misidentified from the start → this code. A correctly-set boundary drifted over time → GER-314.
- [**GER-420**](/ger/codes/420) — The control is wired but bound to the wrong commit point → this code. The control is declared in policy but never wired into production → GER-420.
- [**GER-426**](/ger/codes/426) — The true point of no return was never correctly located → this code. The agent exceeded a correctly-located boundary → GER-426.
