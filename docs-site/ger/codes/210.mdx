## Definition

Detection fired, internal action taken, no audit record created by design. The platform suppressed the trail deliberately.

## Distinct from

- [**GER-204**](/ger/codes/204) — Action taken with deliberate absence of record → this code. No action taken, the decision itself is logged → GER-204.
- [**GER-205**](/ger/codes/205) — Audit trail suppressed for an action that happened → this code. Generation completed and visible, then post-hoc unmade → GER-205.
