## Definition

Decision authority for a class of actions silently shifts to a new actor (a sub-agent, a downstream system, a vendor model) without the rules following. The new authority makes decisions under a rule set that doesn't cover the action.

## Distinct from

- [**GER-316**](/ger/codes/316) — Authority silently shifts to new actor without rules following → this code. Authority expired but system continues to honor it → GER-316.
