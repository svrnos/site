*Operator / Platform Errors*

## Definition

Safety rule written ambiguously or self-contradictorily. Enforcement engines default to allow.

## Distinct from

- [**GER-404**](/ger/codes/404) — Rule exists but cannot be parsed consistently → this code. No rule exists in the active ruleset → GER-404.
- [**GER-409**](/ger/codes/409) — Single rule malformed and unenforceable → this code. Multiple valid rules in collision with no resolver → GER-409.
