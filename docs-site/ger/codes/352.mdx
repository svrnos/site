## Definition

Divergence between human-readable policy and machine-enforced rules where the system enforces a semantically different version of the documented intent. Both policy and rule exist; they no longer match.

## Distinct from

- [**GER-307**](/ger/codes/307) — Rule invoked but enforces different semantic than written policy → this code. Rule exists but is never invoked at all → GER-307.
- [**GER-420**](/ger/codes/420) — Rule wired into production but mis-translated → this code. Rule stated in policy but never wired into production → GER-420.
