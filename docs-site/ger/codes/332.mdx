## Definition

A controller (orchestrator agent, supervisor team, parent process) operates under a constraint that is not propagated to subordinate agents it delegates to. Sub-agents execute without the constraint that would have prevented harm.

## Distinct from

- [**GER-337**](/ger/codes/337) — Constraints fail to propagate to sub-agents → this code. Non-constraint information (intent, context) attenuates across agents → GER-337.
- [**GER-347**](/ger/codes/347) — Constraint dropped during delegation → this code. Original intent mutated as each agent reinterprets → GER-347.
