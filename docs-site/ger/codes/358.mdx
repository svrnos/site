## Definition

Steering or escalation gate logic is misconfigured or inverted, routing the highest-risk cases away from human review. The gate exists but routes in the wrong direction.

## Distinct from

- [**GER-420**](/ger/codes/420) — Gate exists but routes the wrong direction → this code. No enforcement gate is wired at all → GER-420.
