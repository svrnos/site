*Operator / Platform Errors*

## Definition

Operator deploys a multi-step agent chain without computing end-to-end reliability as a function of per-step reliability. The compound failure rate is catastrophically higher than any individual step's apparent reliability.

## Distinct from

- [**GER-422**](/ger/codes/422) — Operator honest per-step measurement, compound math not done → this code. Vendor overstated capability → GER-422.
