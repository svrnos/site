*Operator / Platform Errors*

## Definition

Volume of safety flags generated exceeds the capacity of the governance system to process them. Cases are dropped, sampled, or auto-closed without review.

## Distinct from

- [**GER-420**](/ger/codes/420) — Supervisor at the gate but adds no real review → this code. Stated supervision policy never wired → GER-420.
- [**GER-503**](/ger/codes/503) — Governance overloaded despite intent to serve → this code. Governance component intentionally offline → GER-503.
