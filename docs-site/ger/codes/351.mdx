## Definition

Multi-agent architecture lacks a dedicated Assurance plane (no Evaluator agents, no Critic agents, no validation layer). Output flows from planner to executor to user without intermediate validation.

## Distinct from

- [**GER-339**](/ger/codes/339) — No verification role exists in architecture → this code. Verification role exists but is diffused with no single owner → GER-339.
