*Structural Moves*

## Definition

Drift in the option topology a system presents to users: default selections, ranking, framing gradients, and surfaced choices shift over time in ways that change user behavior without any change to the formal rule set. The user is influenced into actions they wouldn't have chosen, but no rule has been violated. Design governs agency.

## Distinct from

- [**GER-314**](/ger/codes/314) — Drift in what the user is shown (defaults, ranking, surfaced choices) → this code. Drift in what the system will execute (gates, thresholds, access) → GER-314.
- [**GER-318**](/ger/codes/318) — Drift in the menu the user sees → this code. Model's internal world drifting from external truth → GER-318.
