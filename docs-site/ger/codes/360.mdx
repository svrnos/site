## Definition

A multi-turn session accumulates escalating risk that no layer aggregates across turns. Per-turn governance fires correctly; only session-level aggregation is absent, so risk is never detected to escalate.

## Distinct from

- [**GER-351**](/ger/codes/351) — Per-turn assurance fired; session aggregation is absent → this code. No assurance plane exists at any level → GER-351.
- [**GER-501**](/ger/codes/501) — Risk is never aggregated/detected across turns → this code. Risk is detected but has no escalation path → GER-501.
