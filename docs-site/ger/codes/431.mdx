*Operator / Platform Errors*

## Definition

Third-party model vendor pushes a model update — minor version bump, weight refresh, RLHF re-tune — and the operator deploys the new variant without local re-validation of safety properties.

## Distinct from

- [**GER-309**](/ger/codes/309) — Operator did not re-measure after vendor model update → this code. Vendor itself measured harm and shipped → GER-309.
