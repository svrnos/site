## Definition

Platform removes or revises a publicly committed, actively enforced governance constraint without a documented re-evaluation, public explanation, or stakeholder notification commensurate with the constraint's prior commitment level. The failure is procedural: the decision to retire may be defensible, but the constraint is retired without the governance process that established it.

## Distinct from

- [**GER-309**](/ger/codes/309) — Constraint removed under pressure, no measurement step → this code. Vendor measured harm before deployment and shipped anyway → GER-309.
- [**GER-420**](/ger/codes/420) — Publicly committed constraint actively retired → this code. Stated prohibition never wired into production from the start → GER-420.
