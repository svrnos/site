## Definition

Platform removes or revises a publicly committed, actively enforced governance constraint under non-technical pressure (competitive, regulatory, commercial, or political) rather than changed technical risk.

## Distinct from

- [**GER-309**](/ger/codes/309) — Constraint removed under pressure, no measurement step → this code. Vendor measured harm before deployment and shipped anyway → GER-309.
- [**GER-420**](/ger/codes/420) — Publicly committed constraint actively retired → this code. Stated prohibition never wired into production from the start → GER-420.
