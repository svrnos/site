*1xx*

## Definition

A deployed model diverges from reference performance due to deployment-surface variance such as chip-revision quantization or unvalidated firmware interaction.

## Distinct from

- [**GER-431**](/ger/codes/431) — Substrate/deployment-surface variance is the failure → this code. An unvalidated vendor change is the failure → GER-431.
