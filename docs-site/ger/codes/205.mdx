*Success States*

## Definition

Generation completed and visible to the user, then retroactively suppressed by a downstream classifier. No audit trail, no user signal, no appeal.

## Distinct from

- [**GER-210**](/ger/codes/210) — Generation succeeded and was visible to the user, then unmade → this code. Action taken, audit trail deliberately suppressed by design → GER-210.
- [**GER-420**](/ger/codes/420) — Generation visible to user then retroactively removed by classifier → this code. Stated prohibition exists in policy but enforcement never wired into production → GER-420.
