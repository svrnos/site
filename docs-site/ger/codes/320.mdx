## Definition

AI system applies a rule from one jurisdiction to a case that belongs to another. The rule itself is correct in its domain; the binding to this case is wrong.

## Distinct from

- [**GER-334**](/ger/codes/334) — Wrong-jurisdiction rule applied to a case → this code. Correct-jurisdiction rule with expired validity → GER-334.
