*Structural Moves*

## Definition

A principal's authority for a class of actions expires (employment ends, mandate revoked, certificate lapses) but the system continues to honor commands from that principal. Authority expired in the org chart; system still respects it.

## Distinct from

- [**GER-312**](/ger/codes/312) — Authority expired but system still honors it → this code. Authority shifted to new actor without rules following → GER-312.
