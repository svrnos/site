*Infrastructure Failures*

## Definition

Safety stack crashes or fails open. An unhandled exception causes the governance system to remove all guardrails during live operation.

## Distinct from

- [**GER-502**](/ger/codes/502) — Platform own governance code crashed → this code. Platform depended on external service that returned bad response → GER-502.
